强化学习最佳学习资料

从经典入门到 2026 年 Post-training 前沿

2025–2026 年 AI 圈最热的关键词——DeepSeek-R1、OpenAI o1/o3、Agentic RL——本质上都是同一件事：用强化学习"逼"出大模型的推理与智能体能力。RL 从学术边缘重新站到舞台中央。这份清单帮你从直觉走到前沿：先选一本好读的书、一门好课建立直觉，再补理论，最后看懂 post-training 里的 RL 是怎么被"降级使用"（RLVR）和"重新升级"（Agentic RL）的。

一经典书籍：要求易懂，按需挑

三本风格迥异的入门读物，按你的需求挑一本开读。

中文入门首选

Datawhale《EasyRL 蘑菇书》

基于李宏毅课程整理，从策略梯度讲到 PPO、DQN、Actor-Critic、模仿学习，每个算法都配可运行代码和习题。免费在线阅读，GitHub 开源，是中文世界最好上手的教材。

在线阅读 https://datawhalechina.github.io/easy-rl/ GitHub https://github.com/datawhalechina/easy-rl
理论"圣经"

Sutton & Barto《Reinforcement Learning: An Introduction》第 2 版

RL 公认的经典教材，MIT Press 2018 年出版，官网提供免费完整 PDF、代码和课件。不涉及神经网络，纯讲 MDP、动态规划、TD 学习、策略梯度这些地基，适合当长期参考书。

免费 PDF http://incompleteideas.net/book/the-book-2nd.html
书、课一体

王树森《深度强化学习》

北大博士王树森，公开课播放量超百万，中文大白话风格，从价值学习/策略学习分模块讲起，非常零基础友好。PDF 初稿、课件、视频全部开源。

GitHub https://github.com/wangshusen/DRL

二大神课程：按你的风格挑

四门口碑课程 + 一份关于 Karpathy 的特别提醒。

李宏毅（台大）中文入门体验天花板

不从 MDP 形式化讲起，直接从"怎么拿到最大奖励"切入 Policy Gradient 与 PPO，再用 Atari 游戏讲 Q-learning 与 DQN 升级，穿插 A2C/DDPG、Reward Shaping、Imitation Learning，幽默通俗。B 站历年合集，可先看 2021 版再补早年版本。

B 站合集 https://www.bilibili.com/video/BV1XP4y1d7Bk/ 2025 版机器学习系列（含 RL 模块） 配套学习笔记 https://github.com/morningsky/NTU-ReinforcementLearning-Notes
另注：李宏毅 2026 年还推出了 AI Agent 新课（覆盖 Harness Engineering、AI Agent 系列）。

David Silver（UCL / DeepMind）理论最完整

AlphaGo 首席作者亲授的经典 10 讲：MDP → 动态规划 → Model-free 预测与控制 → 策略梯度 → 探索与利用。

课程主页 https://davidstarsilver.wordpress.com/teaching/

关于 Karpathy：他其实没有正式的 RL 课

截至 2026 年，Karpathy 的 YouTube 技术线只有《Neural Networks: Zero to Hero》（从零手写神经网络和 GPT），并不是 RL 课程。他"教 RL"靠以下三篇必读：

《Deep RL: Pong from Pixels》（博客，2016，RL 直觉启蒙）https://karpathy.github.io/2016/05/31/rl/ 《RLHF is just barely RL》（X 长文，用 AlphaGo 对比讲透 RLHF 本质与局限）https://x.com/karpathy/status/1821277264996352246 2025 年 Dwarkesh 播客访谈（"RL is terrible, but everything else is much worse"）https://www.dwarkesh.com/p/andrej-karpathy
提醒：神经网络基础不牢的话，Zero to Hero 仍是全网最佳免费前置课。

三最新进展：Post-training 里的 RL 到底怎么用

一条主线

RLHF 起点

InstructGPT 时代，奖励模型 + PPO。

DPO 简化

去掉显式奖励模型，直接偏好数据优化。

RLVR 转折点

Ai2 Tülu 3 用可验证函数替代奖励模型，GSM8K/IFEval 比 DPO 再提升最多 3.3 分，见 https://allenai.org/blog/tulu-3-technical。

GRPO 工程关键

DeepSeek-R1 省掉 critic，组内相对分数当 baseline，2026 共识：推理/对齐任务直接用 GRPO。

Agentic RL 当前前沿

从单步 MDP 到多步 POMDP，综述 https://arxiv.org/abs/2509.02547。

推理模型时代：o1 → R1 → 2026

OpenAI o1 带火推理模型；DeepSeek-R1 公开 RLVR 训练推理模型的配方，R1-Zero 证明纯 RL、零监督数据就能让推理能力"自发涌现"（论文 https://www.nature.com/articles/s41586-025-09422-z）；到 2026 年（如 DeepSeek V4 用 SFT + RLVR/GRPO 训练多个推理专家），业内共识：推理能力主要是 RL 的成就，而不是 SFT 的（参考 https://ascenttrainings.com/feeds/blog/reinforcement-learning-post-training 与 https://magazine.sebastianraschka.com/p/controlling-reasoning-effort-in-llms）。

Agentic RL：从"生成一句"到"做一件事"

NVIDIA 工程指南的实操工作流：SFT（如需）→ 用 GRPO + 可验证奖励训练 → 环境评估 → 复盘失败 → 循环，适用于 JSON 校验、CLI 命令、代码测试、工具调用、模拟器结果等能算法化判定对错的场景（https://developer.nvidia.com/blog/mastering-agentic-techniques-ai-agent-reinforcement-learning/）。

该信什么：Karpathy 的清醒视角

RL 靠 verifier 比靠显式监督能撬动更多智能，但单一标量奖励在长程任务上可能不够，未来可能需要"review/reflect → 提炼 lesson"的新学习范式。
